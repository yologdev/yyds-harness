Implementation Notes:
- The fix is in the panic hook at lines 72-90 (the `if let Some(ref model_call_id) = CURRENT_MODEL_CALL_ID.with(|c| c.take())` block).
- CURRENT_MODEL_CALL_ID is `Cell<Option<String>>`. Since String is not Copy, you cannot peek without taking. Use the replace-to-peek pattern:
  ```rust
  let model_call_id = CURRENT_MODEL_CALL_ID.with(|c| {
      let val = c.take();      // take ownership
      let clone = val.clone(); // clone for the payload
      c.set(val);              // restore so record() sees it
      clone
  });
  if let Some(ref id) = model_call_id {
      record(EventType::ModelCallCompleted, Actor::Harness, json!({...}));
      CURRENT_MODEL_CALL_ID.with(|c| { c.take(); }); // now clear it
  }
  ```
- Update the test at line 8677 to match the new peek-before-record pattern.

  1. Initializes state
  2. Records ModelCallCompleted WITHOUT calling set_current_model_call_id first
  3. Verifies the event stream contains ModelCallCompletedWithoutStart
